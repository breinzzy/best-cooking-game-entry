LANTERN NOODLE — Noodle Stall: a night-market noodle stand. Read the order board, layer ingredients into the bowl, stir until simmered, move it to the pass shelf and ring the bell before the customers walk out. Four original noodle dishes (Chicken Noodles, Spicy Laksa, Fried Noodles, Balado Noodles), seven ingredients, a 3-minute shift with a service rush, combos, tips and hearts. Keyboard (1–7, Space, Enter, Del, P, M) and mouse; sounds are synthesised in the browser, no audio files, no network requests, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and click START COOKING.

Or open `game/index.html` directly in Chrome — no server, no build step, no
network requests at all (plain scripts, synthesised audio, vector art only).
